# Portfolio_JayzirTech 🚀

> **Personal Engineering & Developer Portfolio** showcasing the synergy between **Mechatronics Engineering**, **Backend Architecture**, and **Data Engineering**.

---

## 🌌 Interactive Experience: Antigravity Starfield
This portfolio features an interactive HTML5 Canvas background effect inspired by Google Antigravity:
* **Interactive Physics:** Starlight particles twinkle and gently repel (anti-gravity force) in response to real-time cursor movement.
* **Dynamic Constellations:** Procedural glowing cyan connection lines link nearby stars and track the user's cursor.
* **Pure Vanilla Performance:** 60fps lightweight `requestAnimationFrame` implementation with zero external dependencies.

---

## 🛠️ Technologies Used
* **HTML5:** Semantic architecture with modern accessibility standards.
* **SASS (SCSS) & CSS3:** Modular stylesheets, CSS variables, glassmorphism, responsive grid layouts, and custom scroll interactions.
* **JavaScript (ES6+):** Interactive Canvas rendering, DOM manipulation, asynchronous API consumption, and modular scripts.

---

## ✨ Featured Projects Showcased
* **DataMart Analytical ETL Pipeline:** End-to-end containerized ETL orchestrated with Apache Airflow (Celery & RabbitMQ), FastAPI, and PostgreSQL.
* **Mercado Nube Analytics Engine:** Dimensional Data Warehouse featuring Star Schema and Slowly Changing Dimensions (SCD Type 2).
* **Ocularis — Optical Simulation:** Real-time optical physics modeling and patient education tool for optometrists.
* **FastAPI Microservice Backend:** Clean architecture RESTful microservice with relational database integration.

## ⚙️ Installation & Usage
1. Clone this repository:
   ```bash
   git clone https://github.com/JayzirTech/portfolio_JayzirTech.git
   ```
2. Open `index.html` directly in any modern web browser.
3. (Optional) If editing SCSS files, compile using SASS or the *Live Sass Compiler* extension in VS Code.
